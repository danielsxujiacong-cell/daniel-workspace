# Handoff

## Current state

- **Updated:** 2026-10-11
- **Stage:** V3.5-B.2 fixes the reported OAuth-success/Workspace-disconnected race. Commit `2af0a01` is pushed; signed-in private-repository acceptance remains unverified in this environment.
- **Implementation:** Workspace now starts GitHub user authorization directly for an existing installation. The Worker uses a signed, single-use, 10-minute state, finds the matching App installation in the authorized user's installation list, and discards the user token after verification. If no installation exists, it falls back to the install flow; setup callbacks accept installation and repository-scope updates. Short-lived installation tokens read selected repository metadata and commit activity; KV maps the validated Workspace user to the installation ID.
- **Frontend:** Projects can connect/refresh the GitHub App. Home pinned cards and AI Daily Brief use matching public or authorized private repository snapshots. Private snapshots stay in the current browser cache and are not sent to Supabase. Cached private information remains visible with offline/authorization status notices.
- **Root cause and fix:** The return path started a silent private-repository refresh before checking `github_app=connected`, then started a second refresh. Both reads could race the callback's KV write or hit a cached miss for the stable `user:{Supabase UUID}` mapping. On that `github_not_connected` response the old client immediately marked the app disconnected. The callback state and mapping use the same validated Workspace user; OAuth/API auth does not rely on cookies. API calls use the Supabase Bearer token with `credentials: omit`, and callbacks use signed one-time state. The client now handles the callback first, shows a pending state, and retries repository and snapshot reads for about 65 seconds.
- **Deployment:** Cloudflare Worker version `82e9677f-6093-4a6c-bfaf-85f486a69e27` remains live; `/health` is healthy and unauthenticated `/api/github/status` returns the expected `401 github_session_required`. Commits `2af0a01` (fix) and `66ef8dc` (handoff) are pushed. Cache-busted GitHub Pages and EdgeOne-backed `workspace.danielxu.cn` assets now expose the V3.5-B.2 import and retry logic.

JavaScript syntax checks and `git diff --check` pass. No signed-in browser tab was available for live private-repository acceptance; GitHub authorization was not repeated here.
